# Dynamic Budget Tracker

A simple GUI-based budget tracking application built using Python and Tkinter.

## 📋 Description

The **Dynamic Budget Tracker** helps users manage their monthly finances by allowing them to input income and expenses and view a summary of their remaining budget. The application includes a basic login screen for access control and a main interface for budget tracking.

## 💡 Features

- Login screen with username and password validation.
- Monthly income input.
- Multiple expense input (comma-separated values).
- Automatic calculation of remaining budget.
- View summary of total income, expenses, and balance.
- GUI built with Tkinter.

## 🛠️ Technologies Used

- Python 3.x
- Tkinter (standard GUI library for Python)
